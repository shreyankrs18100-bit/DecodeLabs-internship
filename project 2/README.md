# Data Classification Using AI

## Project Overview

This project demonstrates a basic supervised machine learning classification model using the Iris dataset.

## Objective

To understand data loading, data splitting, model training, testing, and prediction using a classification algorithm.

## Technologies Used

* Python
* Scikit-Learn
* Pandas

## Algorithm Used

Decision Tree Classifier

## Steps Performed

1. Loaded Iris Dataset
2. Split dataset into training and testing data
3. Trained Decision Tree model
4. Predicted test data
5. Calculated accuracy score

## Result

The model successfully classified flower species with high accuracy.
