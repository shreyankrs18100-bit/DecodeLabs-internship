# AI Recommendation System

## Project Overview

This project is a simple AI Recommendation System developed using Python. The system recommends movies or courses based on user interests and preferences.

## Objective

To understand the basic concepts of recommendation systems, preference matching, and pattern-based suggestions.

## Features

* Takes user preferences as input.
* Matches interests using predefined logic.
* Recommends relevant items.
* Easy to use and interactive.

## Technologies Used

* Python
* If-Else Statements
* User Input Handling

## How to Run

1. Install Python.
2. Save the code as `recommendation.py`.
3. Open Terminal or Command Prompt.
4. Run:

python recommendation.py

## Sample Output

Choose a genre (action/comedy/horror/scifi): action

Recommended Movies:

* John Wick
* Mission Impossible
* Mad Max

## Learning Outcomes

* Understanding recommendation systems.
* Preference matching using logic.
* Building interactive AI-based applications.
