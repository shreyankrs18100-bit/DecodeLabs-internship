# Rule-Based AI Chatbot

## Project Overview

This project is a Rule-Based AI Chatbot developed using Python. The chatbot interacts with users and provides predefined responses based on user inputs using if-else conditions and a continuous loop.

## Objective

The objective of this project is to understand the basic concepts of Artificial Intelligence, decision-making logic, and control flow through a simple chatbot application.

## Features

* Responds to greetings such as Hi, Hello, and Hey.
* Provides information about GATE examination.
* Displays current date and time.
* Answers questions related to Python, C Language, AI, and internships.
* Runs continuously until the user exits.
* Handles unknown inputs gracefully.

## Technologies Used

* Python 3
* If-Else Statements
* While Loop
* Datetime Module

## How to Run the Project

1. Install Python on your system.
2. Save the chatbot code as `project1.py`.
3. Open Terminal or Command Prompt.
4. Navigate to the project folder.
5. Run the following command:

python project1.py

## Sample Interaction

You: hi

Bot: Hello! Nice to meet you.

You: gate

Bot: GATE is a national-level examination for engineering graduates.

You: bye

Bot: Goodbye!
